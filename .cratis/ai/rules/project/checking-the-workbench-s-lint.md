## Checking the Workbench's lint

Use **`yarn lint:ci`**. `yarn lint` is `eslint --fix`, and one of the things it "fixes" is the
`// @generated by Cratis …` header on every generated proxy — it replaces the provenance line with
the license header, silently, across the whole tree. That header is the marker saying the file is
output and must not be edited.
