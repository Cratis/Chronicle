title: Cratis Chronicle reducer event sequence selection
description: Choose the event sequence a Cratis Chronicle reducer reads, override inferred inbox routing, or explicitly select the default event log.
---

<span id="event-sequence"></span>

A Cratis Chronicle reducer reads one event sequence: an ordered stream such as the event log or an inbox. Select a sequence explicitly when the reducer should read somewhere other than its default or inferred source.

In .NET, reducers read the default event log unless event-store metadata points their handled events to another store's inbox. Use `[EventSequence]` or the `eventSequence` parameter on `[Reducer]` to override that selection.

For a [self-reducing read model](self-reducing-read-models), place sequence configuration on the model itself. The .NET client applies the same selection and external-store routing rules as it does for a separate reducer. A sequence attribute chooses the input; it does not turn the model into a projection.

## Using the `[Reducer]` Attribute

When you are already using the `[Reducer]` attribute to set a custom identifier or other options, use its `eventSequence` parameter instead of adding a separate `[EventSequence]` attribute:

Either form selects the sequence. If both are present in .NET, `[EventSequence]` takes precedence. Keep the selection in one place so a later change does not leave a conflicting value behind.

## Convenience: `[EventLog]`

Use `[EventLog]` when you want to be explicit that the reducer reads from the default event log, even when event types in the assembly carry a `[EventStore]` attribute pointing elsewhere:

<ChronicleClientTabs snippet="reducers/event-sequence/event-log-attribute" />

`[EventLog]` explicitly selects the default log instead of inferring an inbox from event-store metadata on the events. Use the event-log sequence name when configuring this selection through a sequence parameter.

## External Event Store Inbox Routing

If the events belong to another event store, follow [Subscribe Reducers to External Event Stores](external-event-store-subscriptions) to let Chronicle forward them from the source outbox to a local inbox. In .NET, `[EventStore]` on the reducer selects that inbox and cannot be combined with explicit sequence configuration, including `[EventLog]`.

## When to Use `[EventSequence]` Explicitly

Use an explicit sequence to read from a known sequence instead of the inferred one, or to keep a reducer on the local event log despite external-store metadata on its events. Sequence selection chooses where events come from; it does not narrow delivery by tag, event source type, or stream type. For those rules, continue with [reducer event filtering](filtering).
