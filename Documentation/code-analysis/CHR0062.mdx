---
title: "CHR0062: Concurrency applies across event sources"
description: "CHR0062 reports a definition or stream concurrency declaration that omits EventSourceId."
---

## Rule description

A nonempty `Concurrency` declaration on an event source definition or one of its streams that omits `ConcurrencyDimensions.EventSourceId` applies across event source instances. It is an independent cross-source condition, not a guard for the state a command read.

`None` and undeclared concurrency are not reported. The rule evaluates constant flags, including combined dimensions, aliases and casts.

## Severity

Info

## How to fix

Include `EventSourceId` when the condition should apply per source. The code fix adds that dimension without dropping the existing ones. This changes the predicate; accept it only when per-source concurrency is intended.

A deliberate cross-source condition can remain as declared. Use a decision read to protect a state-dependent decision; a concurrency declaration alone does not do that.
