title: "CHR0079: A relation of a graph view must follow an edge"
description: "CHR0079 reports a graph view relation whose Follows type is not marked as an edge, and shows how to follow a declared edge type instead."
---

## Rule description

A relation follows an edge of the graph from the node of the view to another view. The rule reports a member marked with `Follows<TEdge>` whose `TEdge` is not marked with `[Edge]`.

## Severity

Error

## How to fix

Give `Follows<TEdge>` the edge type that connects the two nodes. If the graph has no such edge yet, declare one with `[Edge]` and project it from the events that connect the nodes.
