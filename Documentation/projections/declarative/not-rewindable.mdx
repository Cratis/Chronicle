# Projection with NotRewindable

The `NotRewindable()` method sets `IsRewindable` to `false` on the projection definition. This is a property of the projection definition and is distinct from observer replayability.

## How it works

`NotRewindable()` records `IsRewindable = false` on the projection definition that the client registers with the Kernel. It does not change which events the projection subscribes to or how it handles them.
