description: "Call NotRewindable() to set IsRewindable to false on a Cratis Chronicle projection definition without changing its event mappings or subscriptions."
---
In Cratis Chronicle, `NotRewindable()` records `IsRewindable = false` on a projection definition. Use it to declare that flag, not to prevent observer replay: the flag is separate from observer replayability and does not change event handling.

The client registers this definition with the Kernel with `IsRewindable` set to `false`. The `From` and `FromEvery` mappings still determine which values the projection writes.

## How it works

The builder starts with `IsRewindable` set to `true`; `NotRewindable()` changes it to `false`. The Kernel carries that value on the engine's projection. Observer replayability is classified separately, so do not use this flag as a substitute for replay policy.

Here, `FromEventSequence` selects the events, `Passive()` selects on-demand computation, and the mappings set status and timestamps. Those choices are independent of `NotRewindable()`.
