# Projection With FromAll

`FromAll` subscribes to **every event type in the event sequence**, not just event types declared by the projection. It can create or update a read-model instance for any event source, keyed by the event source id unless you configure another key. Use [FromEvery](./from-every) instead when mappings should apply only to event types the projection already handles.

Use `FromAll` in .NET for sequence-wide mappings such as per-source event counts. The `all` block in the declaration language has the same subscription scope. Child-projection inclusion is a separate setting; it does not limit which root event types `FromAll` subscribes to.

## With Event-Specific Mappings

`FromAll` can sit beside event-specific `From` mappings, but the `FromAll` mapping also processes event types not shown in this example. Those events can create instances without the event-specific business fields. If metadata should update only for the events listed in `From`, use `FromEvery` instead.

## Counting Into A Dictionary With A Dynamic Key

`FromAll` also supports `Count`, `Increment`, and `Decrement` against a dictionary-typed property, where the key is resolved per event from a value on the `EventContext` — for example, one counter per event type, keyed by the event type identifier. The dictionary's value type is always `int64` for these operations; the key is always `string`.

<ChronicleClientTabs snippet="projections/declarative/from-all/dictionary" />

The model-bound `[FromAll]` attribute does not yet support this dictionary form — use the fluent API above until it does.

## FromAll And FromEvery

| API | Use it when |
| --- | --- |
| `FromAll` | You are using the .NET declarative projection API and want to express an all-events mapping. |
| `FromEvery` | You want mappings applied to the projection's own handled event types, without subscribing to unrelated event types. |

Prefer event context sources for audit fields because every event has the same context shape. Use event payload properties only when the event contracts intentionally share the same property.
