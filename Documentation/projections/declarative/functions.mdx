---
title: Chronicle projection functions for counters and totals
description: Chronicle projection functions update counters and totals as events are processed. Use Count for occurrences and Add or Subtract for event amounts.
---
Cratis Chronicle projection functions maintain counters and totals from events, so your application can read a login count, stock quantity, or account balance without calculating it on each query. Choose a function according to what the event contributes: one occurrence, one item, or an amount carried in the event.

## Supported types

The kernel supports numeric targets including `int`, `long`, `float`, `double`, and `decimal`. It uses the target property's schema to select the numeric type and converts values for the operation. Declare a target type suitable for the values you accumulate; client-language type names differ.

## How functions work

Each function reads the property's current value, applies the change, and stores the result for the next event. A missing numeric property starts at zero. If the read model needs another starting value, declare [initial values](initial-values) before accumulating events.

The read model key determines which instance receives the change. A balance keyed by account accumulates that account's events, not every account's events. See [composite keys](composite-keys) when one identifier is not enough to select the instance.
