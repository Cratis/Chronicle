---
title: Chronicle projections for optional nested objects
description: Use Nested in a Chronicle projection to update one optional object, such as an active contract. ClearWith sets the object to null when it ends.
---
Use `Nested()` in a Cratis Chronicle projection when a read model has one optional object, such as an employee's active contract or a task's current assignee. Events update properties inside that object, and `ClearWith<TEvent>()` sets it to `null` when the relationship ends. Use [children collections](children) instead when the parent owns several items identified by keys.

## How nested objects work

The set event populates `Command` on the parent. Later matching events update only the nested properties they map, leaving other properties unchanged. They do not replace the whole object.

The clear event sets `Command` to `null`. A later set event can populate it again. This lets the read model distinguish an absent command from a command whose properties happen to have default values.
