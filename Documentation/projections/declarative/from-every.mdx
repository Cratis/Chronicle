# Projection With FromEvery

Use an every-event mapping in a declarative projection when a read model property should update whenever any event handled by the projection is processed. This is most useful for audit metadata, event source identifiers, and other fields that should stay synchronized with the latest event.

The exact API name depends on the client. .NET and TypeScript expose `FromEvery` / `fromEvery`, while Elixir exposes `from_every`.

## Constant Values

In .NET, `FromEvery` and `FromAll` both support `.Set(m => m.Status).ToValue("active")` to assign a constant whenever a matching event is processed. Concept values are unwrapped. Enums with an `int` underlying type use their numeric value; other enums use their name. Use `.ToValue<string?>(null)` to clear a nullable property.

## Child Projection Inclusion

The kernel now honors the child-inclusion flag. In .NET, `FromEvery` includes events handled only by child projections by default, including nested child collections. These mappings update the containing parent using the child's resolved parent key, not a new root keyed by the child identifier. Existing fluent projections therefore start updating parent audit fields on child-only events.

Call `ExcludeChildProjections()` to keep every-event mappings local to the level where they are declared. That level's own `from` and `join` events still apply the mappings. In the declaration language, `every` also includes child events by default; add `exclude children` to opt out.

<ChronicleClientTabs snippet="projections/declarative/from-every/exclude-children" />

Use a root `FromAll` mapping only when the parent must also observe unrelated event types in the sequence. Its child-inclusion flag is true, so child-only events update their containing parent too. Use `FromEvery` for audit metadata that should follow just the projection's handled events.

## Common Use Cases

| Use case | Typical source |
| --- | --- |
| Audit timestamp | Event context occurrence time |
| Event sequencing | Event context sequence number |
| Correlation tracking | Event context correlation id |
| Event source identification | Event source id |
