<a id="setting-constant-values"></a>

`SetValue` assigns a fixed value to a property when a Cratis Chronicle model-bound projection handles an event of the specified type. Use it when the event itself determines the value, such as an order-canceled event setting an order's status to `"canceled"`, even if the payload has no status property.

## Basic Usage

In C#, apply `SetValue<TEvent>(value)` to the property that should change:

<ChronicleClientTabs snippet="projections/model-bound/set-value/order" />

The two attributes on `Status` select a value by event type. The order-placed event writes `"active"`; the order-canceled event writes `"canceled"`. Neither value needs to be stored in the event payload.

## Supported Value Types

The attribute value must be valid as a compile-time attribute argument. You can use strings, integers, longs, doubles, booleans, and enum values:

<ChronicleClientTabs snippet="projections/model-bound/set-value/thing" />

The example assigns a string, an integer, a boolean, and a double from one event. Choose a value that matches the target property's type.

## Multiple Events

Apply the attribute more than once when several event types set the same property:

<ChronicleClientTabs snippet="projections/model-bound/set-value/subscription" />

The subscription example sets `State` to `"active"`, `"paused"`, or `"canceled"`. Each event writes its declared value whenever it is processed.

## Clearing a Value

Passing `null` clears the member every time the event occurs. Use `ClearWith` when you want the declaration to state that intent directly; it has the same clearing behavior. The member must be nullable. A non-nullable member raises [CHR0048](../../code-analysis/CHR0048), and Chronicle refuses to build the projection because a type default is not the same as an absent value.

For nullable-member examples and the fluent `Clear` equivalent, see [Clearing Values](clearing).

## SetValue vs SetFrom vs ClearWith

| Attribute | Source | When to use |
|---|---|---|
| `SetValue<TEvent>(value)` | Compile-time constant | The value does not come from the event payload |
| `SetFrom<TEvent>(property)` | Event property | The value comes from a property on the event |
| `ClearWith<TEvent>` | No value | The event takes the value away without putting one in its place |

Use `SetValue` and `SetFrom` together when the event payload supplies some values and the event type determines others:

<ChronicleClientTabs snippet="projections/model-bound/set-value/invoice" />

The invoice-issued event supplies `Amount` through `SetFrom` while setting `Status` to `"issued"` through `SetValue`. The invoice-paid event changes only the status to `"paid"`. For payload mapping options, continue with [Basic mapping](basic-mapping.mdx).
