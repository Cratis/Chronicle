## Start locally

<Steps>
1. Start the reviewed Chronicle 16.38.2 development image by its multi-platform
   OCI manifest digest.

   ```bash
   docker run --rm -d --name chronicle \
     -p 27017:27017 -p 35000:35000 \
     cratis/chronicle@sha256:bc4d23570d29fdfb31a8f5ae689f6538e74ff2db7807e981438473d2283f4b07
   ```

2. Wait for the local health endpoint to report readiness. The reviewed
   development profile uses a development certificate, so this command disables
   certificate verification only for this local check.

   ```bash
   curl --insecure --fail --retry 30 --retry-all-errors --retry-delay 1 \
     https://localhost:35000/health
   ```

   Continue when the response prints `Healthy`.

3. Open `https://localhost:35000` in a browser and follow the local
   authentication flow presented by the development profile. Browser handling
   of the development certificate varies by environment.

4. Select the event store and namespace you are authorized to inspect.

5. Review only the runtime state and projection-preview paths needed for the
   evaluation.

6. Stop and remove the container when finished.

   ```bash
   docker rm -f chronicle
   ```

</Steps>

  <Card title="Observer state" icon="list-format">
