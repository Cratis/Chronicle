---
title: Filter Chronicle events by event stream type
description: Apply EventStreamType to a Chronicle reducer or reactor to handle only events appended to a matching stream category, such as payments or shipping.
---
An `[EventStreamType]` filter limits a Chronicle reducer or reactor to a stream category, such as payments or shipping. Use it when one event source produces distinct processing flows and an observer should handle only one of them.

## How the match works

Set `eventStreamType:` when appending and put the matching attribute on the observer. The values must match exactly. The filter selects a stream type, not an individual `EventStreamId`.

The service appends to the `"payments"` stream type, which matches the reactor's attribute. An event with the same payload but a different stream type does not reach this reactor.

## Filter a reducer by event stream type

<ChronicleClientTabs snippet="events/filtering/by-event-stream-type/reducer" />

Only events appended with `eventStreamType: "shipping"` contribute to these shipping totals. Appending the same event with `eventStreamType: "returns"` does not reach this reducer.

## When to choose stream type filtering

Choose stream type filtering to separate flows within an event source. To narrow delivery further, combine it with a [tag filter](by-tag.mdx) or an [event source type filter](by-event-source-type.mdx). Every configured filter category must match.

## Filter by a declared stream

Use `[FromEventSource<TSource>("Stream")]` when an [event source definition](../../event-sources/defining.mdx) already declares the stream. It sets both the stream type and the event source type. [Filter observers by event source and stream](../../event-sources/filtering.mdx) shows how to refer to that definition without repeating the type strings.

The filter only selects events for the observer. To protect a write from concurrent changes, configure a concurrency scope separately. Stream type can narrow that scope so a decision is guarded per stream; see [Event sources and the Dynamic Consistency Boundary](../../event-sources/dcb.mdx).
