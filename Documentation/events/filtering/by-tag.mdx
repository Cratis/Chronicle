# Filter reducers and reactors by tag

Add `[FilterEventsByTag]` to a Chronicle reducer or reactor to select events by a plain tag, such as `vip` or `priority`. This keeps events without a matching tag out of that observer's handler.

## What counts as a matching tag

Chronicle compares the filter value exactly against the plain tags stored with the appended event. Those tags can come from:

- `[Tag]` or `[Tags]` on the event type
- The `tags:` argument when you append the event

Place `[FilterEventsByTag]` on the observer to filter delivery. `[Tag]` and `[Tags]` on a reducer or reactor only label the observer itself; they do not filter incoming events. [Named tags](../../concepts/tagging.mdx#named-tags) are separate name/value metadata and do not participate in this match.

An event with either `vip` or `priority` passes this tag filter; it does not need both. If you also configure an [event source type](by-event-source-type.mdx) or [event stream type](by-event-stream-type.mdx) filter, the event must satisfy those categories too.
