# Filter reducers and reactors by tag

Configure a tag filter when a reducer or reactor should only handle events that carry specific tags. In C#, use `[FilterEventsByTag]`; the tabs show each client's syntax.

## What counts as a matching tag

Chronicle compares the filter tag against the tags on the appended event. Those tags can come from:

- Static tags declared on the event type (`[Tag]` or `[Tags]` in C#)
- Tags supplied when appending the event

Descriptive tags on the reducer or reactor do not filter anything. They only label the observer itself.
