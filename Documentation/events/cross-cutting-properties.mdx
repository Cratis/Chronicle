---
title: Add cross-cutting properties to Chronicle events
description: Use ICanProvideAdditionalEventInformation in the Chronicle .NET client to add shared properties to event payloads without changing each event type.
---
Cross-cutting properties add shared fields to Chronicle event payloads without requiring each event type to declare them. Use them for values supplied outside domain code, such as a tenant identifier or a system-generated timestamp.

In the .NET client, implement `ICanProvideAdditionalEventInformation` to modify the serialized event before it is appended:

<ChronicleClientTabs snippet="events/cross-cutting-properties/provider" />

The provider receives a `JsonObject` containing the event's serialized properties. This example adds `something` and `someTime` to that object, so the appended payload includes both fields even though the event type does not declare them.

Chronicle discovers providers automatically and calls their `ProvideFor` methods during serialization. You do not need to call the provider from each append operation.

These fields belong to the event payload. If you want metadata for selecting events instead, use [tags](appending-with-tags.mdx) and [observer filters](filtering/index.md).
